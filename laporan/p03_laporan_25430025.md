1. Tujuan Praktikum
Praktikum Pertemuan 3 bertujuan untuk memahami cara membuat tabel berdasarkan ERD fisik menggunakan SQL. Selain itu, praktikum ini bertujuan untuk memahami penggunaan tipe data, Primary Key, Foreign Key, serta constraint seperti NOT NULL, UNIQUE, DEFAULT, dan CHECK dalam pembuatan struktur tabel database.
2. Ringkasan Dasar Teori
ERD fisik merupakan rancangan basis data yang menjelaskan struktur tabel secara terperinci, termasuk nama kolom, tipe data, dan aturan yang digunakan pada setiap kolom.
Beberapa konsep yang digunakan dalam praktikum ini adalah:
1. Primary Key (PK) merupakan kunci utama yang digunakan untuk membedakan setiap baris data dalam tabel.
2. Foreign Key (FK) merupakan kunci yang menghubungkan suatu tabel dengan tabel lainnya.
3. Tipe Data digunakan untuk menentukan jenis nilai yang dapat disimpan, seperti INT, VARCHAR, DATE, dan DECIMAL.
4. NOT NULL digunakan agar suatu kolom wajib memiliki nilai.
5. UNIQUE digunakan untuk mencegah nilai yang sama pada kolom tertentu.
6. DEFAULT digunakan untuk memberikan nilai bawaan jika nilai tidak ditentukan.
7. CHECK digunakan untuk membatasi nilai berdasarkan kondisi tertentu.
8. AUTO_INCREMENT digunakan untuk menghasilkan nomor secara otomatis pada kolom bilangan bulat.

3.2 Membuat Tabel Petugas
Tabel petugas digunakan untuk menyimpan data petugas yang bekerja di Kopma.
CREATE TABLE petugas (

3.5 Membuat Tabel Barang
Tabel barang digunakan untuk menyimpan data barang yang dijual di Kopma.
CREATE TABLE barang (
    id_barang INT AUTO_INCREMENT PRIMARY KEY,
    kode_barang VARCHAR(10) UNIQUE,
    nama_barang VARCHAR(100) NOT NULL,
    kategori_barang ENUM('ATK', 'makanan', 'minuman'),
    harga_jual_barang DECIMAL(12,2)
        CHECK (harga_jual_barang >= 0),
    stok_barang INT CHECK (stok_barang >= 0),
    stok_min_barang INT DEFAULT 5
);

Keterangan: Tabel barang menyimpan kode barang, nama, kategori, harga jual, stok, dan stok minimum. Constraint CHECK membatasi harga dan stok agar tidak bernilai negatif, sedangkan DEFAULT 5 memberikan stok minimum bawaan sebesar 5.

3.6 Membuat Tabel Penjualan
Tabel penjualan digunakan untuk mencatat transaksi penjualan yang dilakukan oleh petugas kepada anggota.
CREATE TABLE penjualan (
    id_penjualan INT AUTO_INCREMENT PRIMARY KEY,
    no_nota_penjualan CHAR(12) UNIQUE,
    tgl_penjualan DATETIME NOT NULL,
    id_petugas SMALLINT,
    id_anggota INT,
    bayar_penjualan DECIMAL(12,2) NOT NULL,

    FOREIGN KEY (id_petugas)
        REFERENCES petugas(id_petugas),

    FOREIGN KEY (id_anggota)
        REFERENCES anggota(id_anggota)
);

Keterangan: Tabel penjualan memiliki relasi dengan tabel petugas dan anggota melalui kolom id_petugas dan id_anggota sebagai Foreign Key.

3.7 Membuat Tabel Detail Penjualan
Tabel detail_penjualan digunakan untuk mencatat barang yang terdapat dalam setiap transaksi penjualan.
CREATE TABLE detail_penjualan (
    id_penjualan INT,
    id_barang INT,
    qty_detail_penjualan SMALLINT,
    harga_satuan_detail_penjualan DECIMAL(12,2) NOT NULL,

    PRIMARY KEY (id_penjualan, id_barang),

    FOREIGN KEY (id_penjualan)
        REFERENCES penjualan(id_penjualan),

    FOREIGN KEY (id_barang)
        REFERENCES barang(id_barang)
);

Keterangan: Tabel ini memiliki Primary Key gabungan dari id_penjualan dan id_barang. Kedua kolom tersebut juga menjadi Foreign Key yang menghubungkan tabel detail penjualan dengan tabel penjualan dan barang.

CREATE TABLE detail_pembelian (

4. Jawaban Titik Analisis
1. Apa fungsi Primary Key dalam tabel?
Primary Key berfungsi sebagai identitas unik setiap baris data sehingga setiap data dapat dibedakan dari data lainnya.
2. Apa perbedaan Primary Key dan Foreign Key?
Primary Key digunakan untuk mengidentifikasi data dalam suatu tabel, sedangkan Foreign Key digunakan untuk menghubungkan data antartabel.
3. Mengapa tabel detail penjualan dan detail pembelian menggunakan Primary Key gabungan?
Karena satu transaksi dapat memiliki beberapa barang. Gabungan ID transaksi dan ID barang digunakan untuk membedakan setiap barang dalam transaksi yang sama.
4. Apa fungsi constraint NOT NULL?
NOT NULL digunakan untuk memastikan bahwa kolom tertentu wajib diisi dan tidak boleh menyimpan nilai NULL.
5. Apa fungsi constraint UNIQUE?
UNIQUE digunakan untuk mencegah nilai duplikat pada kolom yang ditentukan, misalnya kode barang atau NIM anggota.
6. Mengapa tipe data DECIMAL digunakan untuk harga?
DECIMAL digunakan untuk menyimpan angka desimal dengan ketelitian yang sesuai, sehingga cocok untuk menyimpan nilai harga barang dan transaksi.
7. Apa fungsi Foreign Key pada tabel penjualan?
Foreign Key menghubungkan transaksi penjualan dengan petugas yang melayani serta anggota yang melakukan transaksi.
