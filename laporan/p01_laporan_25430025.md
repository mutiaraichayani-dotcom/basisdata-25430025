## 1. Tujuan Praktikum
Praktikum ini bertujuan untuk memahami cara membuat database, membuat akun pengguna, dan memberikan hak akses pada database menggunakan MySQL.

## 2. Ringkasan Dasar Teori
`CREATE DATABASE` digunakan untuk membuat database baru. `CREATE USER` digunakan untuk membuat akun pengguna MySQL, sedangkan `GRANT` digunakan untuk memberikan hak akses kepada pengguna.

## 3. Hasil Langkah Percobaan
Database praktik dibuat dengan nama `kopma_025` dan akun kerja `mhs_025`.

```sql
CREATE DATABASE IF NOT EXISTS kopma_025
CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

CREATE USER IF NOT EXISTS 'mhs_025'@'localhost'
IDENTIFIED BY 'password123';

GRANT ALL PRIVILEGES ON kopma_025.* TO 'mhs_025'@'localhost';
```
**Gambar 1. Hasil pembuatan database dan akun kerja**
