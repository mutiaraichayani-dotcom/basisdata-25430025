1. Tujuan Praktikum

Praktikum ini bertujuan untuk memahami penggunaan MariaDB melalui XAMPP, memeriksa kondisi server, membuat database dan akun pengguna, serta mengatur hak akses pengguna sesuai kebutuhan. Praktikum juga bertujuan memahami pengujian hak akses, penggunaan phpMyAdmin dengan mode cookie, serta menyiapkan repositori Git untuk dokumentasi praktikum dan proyek.

2. Ringkasan Dasar Teori

MariaDB merupakan sistem manajemen basis data yang digunakan untuk menyimpan dan mengelola data. Pada praktikum ini MariaDB dijalankan melalui XAMPP dan diakses menggunakan Command Line Client serta phpMyAdmin.

Pengguna database memiliki hak akses yang berbeda. Akun root memiliki hak administratif, sedangkan akun kerja dan akun developer diberikan hak akses sesuai database yang dikelolanya. Perintah GRANT digunakan untuk memberikan hak akses kepada pengguna.

Praktikum juga membahas keamanan akun dan autentikasi phpMyAdmin. Mode cookie membuat pengguna melakukan login secara langsung sehingga password tidak disimpan di dalam file konfigurasi.

4. Jawaban Titik Analisis
Titik Analisis 1

STRICT_TRANS_TABLES digunakan untuk membuat MariaDB lebih ketat dalam menangani data yang tidak sesuai dengan aturan tabel. Dengan mode ini, kesalahan data dapat diketahui lebih awal.

Titik Analisis 2

ERROR 1045 berkaitan dengan kegagalan autentikasi saat login, misalnya password yang diberikan salah atau tidak sesuai.

Perbedaan:

ERROR 1044 → pengguna tidak memiliki izin untuk mengakses database.
ERROR 1045 → proses login atau autentikasi gagal.

Titik Analisis 3

information_schema tetap dapat terlihat karena merupakan database sistem yang berisi informasi metadata. Sementara itu, akun mhs_025 tidak mempunyai hak untuk menggunakan database mysql, sehingga muncul ERROR 1044.

Titik Analisis 4

Mode cookie lebih aman daripada mode config karena pengguna harus melakukan login dan memasukkan kredensial melalui halaman phpMyAdmin. Password tidak ditulis langsung pada file konfigurasi.
