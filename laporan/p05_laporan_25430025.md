## 1. Tujuan Praktikum

Praktikum ini bertujuan memahami penggunaan Data Definition Language (DDL) untuk membuat dan mengubah struktur basis data, menerapkan primary key dan foreign key, menggunakan constraint, serta menguji perubahan struktur tabel dengan perintah `ALTER TABLE`.

## 2. Ringkasan Dasar Teori

- **CREATE TABLE** digunakan untuk membuat tabel baru.
- **ALTER TABLE** digunakan untuk mengubah struktur tabel.
- **PRIMARY KEY (PK)** menjadi identitas unik setiap baris.
- **FOREIGN KEY (FK)** menjaga hubungan antartabel.
- **CHECK** membatasi nilai berdasarkan kondisi tertentu.
- **UNIQUE** mencegah nilai duplikat pada kolom yang ditentukan.
- **ON DELETE SET NULL** mengatur agar nilai foreign key menjadi `NULL` ketika baris induk dihapus, jika kolom tersebut mengizinkan `NULL`.

## 4. Jawaban Titik Analisis

### 4.1 Mengapa Primary Key Diperlukan?

Primary key digunakan sebagai identitas unik setiap baris sehingga data dapat dibedakan dan dirujuk dengan jelas.

### 4.2 Apa Fungsi Foreign Key?

Foreign key menjaga hubungan antartabel dan membantu mencegah penggunaan nilai referensi yang tidak memiliki baris induk terkait.

### 4.3 Apa yang Terjadi Ketika Data Melanggar Constraint?

MariaDB dapat menolak operasi yang melanggar aturan seperti `CHECK`, `UNIQUE`, atau `FOREIGN KEY`. Pesan galat perlu diperiksa bersama perintah SQL yang dijalankan untuk mengetahui penyebabnya.

### 4.4 Apa Perbedaan ON DELETE CASCADE dan ON DELETE SET NULL?

`ON DELETE CASCADE` menghapus baris terkait pada tabel anak ketika baris induk dihapus. Sementara itu, `ON DELETE SET NULL` mengatur nilai foreign key pada tabel anak menjadi `NULL`, jika kolom tersebut mengizinkan nilai `NULL`.
